# zapret LAN proxy — обход блокировок для всей локальной сети

Позволяет использовать обход zapret с других устройств локальной сети
(телефоны, планшеты, ТВ-приставки, другие ПК): их трафик проходит через
этот ПК, где zapret применяет DPI-обход автоматически.

```
Устройство (телефон/ТВ) ──► HTTP :8080 / SOCKS5 :1080 ──► этот ПК ──► zapret ──► интернет
```

## Быстрый старт

1. Запусти `start-all.bat` (правый клик → можно просто двойной клик,
   скрипт сам запросит права администратора). Он:
   - ставит задачи автозапуска (прокси + zapret стартуют при включении ПК);
   - ставит вотчдог (каждые 5 минут поднимает упавшие прокси/zapret);
   - добавляет правила брандмауэра только для локальных подсетей;
   - чистит битые записи hosts (старый маппинг Discord на чужой IP);
   - запускает всё сразу.
2. Запускать можно сколько угодно раз — двойной запуск безопасен
   (второй экземпляр прокси молча выходит, конфликтов портов не будет).

**Прокси сам не обходит блокировки** — он передаёт трафик устройств через
ПК, где работает zapret (выбранная стратегия из `zapret-strategy.txt`,
по умолчанию `general (MAX).bat`).

## Графическое приложение ZapretControl.exe

На рабочем столе создаётся ярлык **ZAPRET CONTROL**. Приложение собрано из
`zapret-gui.ps1` в один EXE и при запуске запрашивает права администратора
(UAC) — это нужно для служб, задач и тестов.

### Установщик

`ZapretControlSetup.exe` — один файл (~2,2 МБ), внутри весь пакет:

- сам zapret: `bin\winws.exe`, `WinDivert.dll`/`WinDivert64.sys`, `cygwin1.dll`,
  23 стратегии `general*.bat` и `service.bat`; после копирования установщик
  проверяет наличие ключевых файлов и хотя бы одной стратегии;
- мастер установки: папка (по умолчанию `C:\Program Files\ZapretControl`),
  ярлыки на рабочем столе и в меню «Пуск», автозапуск задач, запуск после установки;
- при обновлении сохраняются `zapret-strategy.txt`, `gui-settings.json`,
  `lists\ipset-all.txt` (и его бэкап), игровой фильтр и результаты тестов;
- запись в «Установка и удаление программ», деинсталлятор `uninstall.ps1`
  и ярлык «Удалить ZAPRET CONTROL» в меню «Пуск»;
- тихая установка для скриптов:
  `ZapretControlSetup.exe -Silent -InstallDir "D:\Zapret" -NoAutostart -NoLaunch`.

Пересобрать установщик:

```
powershell -ExecutionPolicy Bypass -File build-installer.ps1
```

Вкладки:

| Вкладка | Что внутри |
|---|---|
| **Обзор** | статусы прокси/zapret/стратегии/автозапуска, сводка состояния, быстрые действия |
| **Прокси** | адреса для устройств, запуск/остановка, автозапуск, задачи, DNS и hosts, проверка соединения |
| **Zapret** | поиск и описание стратегий, запуск выбранной, игровой фильтр, ipset, hosts |
| **Тесты** | стандартные и DPI-тесты, результаты, авто-подбор, остановка тестов |
| **Журналы** | `proxy.log`, `watchdog.log`, `setup.log`, последний результат, фильтр строк |
| **Инструменты** | диагностика, экспорт/копирование отчёта, брандмауэр, `service.bat`, очистка кэша Discord |

Полезные мелочи:

- **Проверить соединение** (на «Обзоре», «Прокси» и «Инструментах») —
  проверяет порты 8080/1080, SOCKS5-рукопожатие, `/health`, YouTube и Discord
  через прокси; результат показывается прямо в окне.
- **Поиск по стратегиям** — фильтр по имени и описание выбранной стратегии
  (техники `--dpi-desync`, маскировка, split-pos, покрытие).
- **Задачи автозапуска** — кнопки «Проверить / Запустить / Остановить» для
  трёх задач планировщика без открытия консоли.
- **Брандмауэр** — показать, создать или удалить правила `zapret LAN proxy`
  (только приватные подсети).
- **Журналы** — фильтр по подстроке, сохранение копии, автообновление.
- **Значок в трее** — «Сворачивать в трей» на вкладке «Инструменты»; меню
  значка: открыть, запустить/остановить/перезапустить всё, проверить соединение.
- **Правый клик по стратегии** — запустить, сделать выбранной, открыть `.bat`
  в блокноте, показать файл в папке.
- **Обновления zapret** — кнопка запускает `service.bat check_updates`.
- **IPSet** — режимы `any` (пустой список), `none` (заглушка) и `loaded`
  (восстановить список из `lists/ipset-all.txt.backup`); в статусе видно число
  записей, кнопки «Обновить ipset» и «Обновить hosts».
- **Настройки окна** — размер, позиция и последняя вкладка запоминаются в
  `gui-settings.json`.
- **Горячие клавиши** — `F5` обновить статусы/журнал, `Ctrl+1…6` переключение
  вкладок.

### Авто-подбор стратегии

- **Авто-подбор стратегии** — DPI-тесты всех `general*.bat`, самый точный
  выбор (может занять 10–30 минут).
- **Быстрый подбор (HTTP)** — быстрые HTTP-тесты (обычно 1–5 минут).
- Победитель сохраняется в `zapret-strategy.txt` и сразу запускается, если
  zapret был включён до тестов.
- **Применить лучшую** — взять победителя из последнего файла результатов
  без повторного прогона.

Во время тестов zapret останавливается, ipset временно переключается в
`any`, затем всё восстанавливается. Пересобрать EXE после правок GUI:

```
powershell -ExecutionPolicy Bypass -File build-exe.ps1
```

Если `ZapretControl.exe` уже запущен, файл занят: закройте окно приложения
или соберите рядом и подмените с правами администратора:

```
powershell -ExecutionPolicy Bypass -File build-exe.ps1 -OutputName ZapretControl.new.exe
powershell -ExecutionPolicy Bypass -File apply-exe-update.ps1 -Restart
```

## Управление

| Скрипт | Действие |
|---|---|
| `start-all.bat` | установить + запустить всё (автозапуск, вотчдог) |
| `stop-all.bat` | выключить всё; не включится само, пока снова не запустишь start-all |
| `restart-all.bat` | перезапустить всё (stop-all + start-all) |
| `zapret-stop.bat` | выключить только zapret (прокси продолжает работать) |
| `zapret-start.bat` | включить только zapret обратно |
| `test-connection.ps1` | проверка прокси/SOCKS5/`/health`/YouTube/Discord без прав админа |
| `uninstall-proxy.bat` | полное удаление (задачи, брандмауэр, процессы) |
| `show-lan-ip.bat` | показать адреса прокси для устройств |
| `ZapretControl.exe` | графический пульт (ярлык на рабочем столе) |

Флаги-файлы в этой папке: `proxy.disabled` / `zapret.disabled` ставятся
stop-скриптами (вотчдог их уважает), `zapret.autostart` включает слежение
вотчдога за zapret.

## Подключение устройств

Узнай IP этого ПК: `show-lan-ip.bat` (например `192.168.1.100`).

| Устройство | Настройка |
|---|---|
| Android | Wi-Fi → сеть → «Прокси» → «Вручную»: `192.168.1.100` : `8080` |
| iOS | Wi-Fi → (i) → «Настройка прокси» → «Вручную»: сервер `192.168.1.100`, порт `8080` |
| Windows/браузер | Системный прокси `192.168.1.100:8080` или SOCKS5 `:1080` |
| Приложения | SOCKS5 `192.168.1.100:1080` (поддерживается UDP: DNS, звонки) |

### DNS и заблокированные сайты

Прокси **сам разрешает имена через DNS-over-HTTPS** (dns.google →
dns.quad9.net → cloudflare-dns.com), если провайдерский DNS вернул
NXDOMAIN/ошибку или подключение по его адресам не удалось. DoH-запросы
проходят через zapret. Поэтому на устройстве отдельный DoH **не обязателен**
— достаточно указать HTTP-прокси.

Если приложение на устройстве само резолвит домены и подключается напрямую
мимо прокси — включи на устройстве Private DNS (`dns.google`) или DoH в браузере.

## Настройка портов (переменные окружения)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `ZAPRET_PROXY_HTTP_PORT` | `8080` | порт HTTP-прокси |
| `ZAPRET_PROXY_SOCKS_PORT` | `1080` | порт SOCKS5 |
| `ZAPRET_PROXY_UDP_RANGE_START`/`_END` | `31000-31999` | диапазон UDP-релея |
| `ZAPRET_PROXY_DOH` | dns.google,quad9,cloudflare | список DoH-URL через запятую |

## Файлы

- `zapret-proxy.py` — прокси (чистый Python 3, только stdlib), v1.4 с `/health`
- `zapret-gui.ps1` — исходник GUI (WinForms), `ZapretControl.exe` — готовая сборка
  (поддерживает `-SelfTest` и `-UiTest` — пишут `self-test.txt` и `ui-test.txt`)
- `build-exe.ps1` — пересборка EXE (использует `tools\ps2exe`, интернет не нужен)
- `ZapretControlSetup.exe` — установщик (мастер, ярлыки, деинсталлятор)
- `build-installer.ps1` — сборка установщика (`-SkipExeBuild`, `-TestBuild`)
- `uninstall.ps1` — удаление программы (`-Quiet`, `-KeepFiles`, `-KeepSystem`)
- `installer\setup-template.ps1` — шаблон мастера установки (payload подставляется при сборке)
- `install-info.json` — метка установки, её создаёт установщик (по ней работает удаление файлов)
- `apply-exe-update.ps1` — замена запущенного EXE новой сборкой (нужен админ)
- `start-all.bat` / `stop-all.bat` / `restart-all.bat` / `zapret-start.bat` / `zapret-stop.bat` — управление
- `test-connection.ps1` — проверка соединения (порты, SOCKS5, `/health`, сайты)
- `install-tasks.ps1` — регистрация задач автозапуска (корректно с пробелами в пути)
- `watchdog.ps1` — проверка здоровья раз в 5 минут (оба порта, лог подрезается)
- `zapret-boot.ps1` — запуск zapret с выбранной стратегией
- `zapret-strategy.txt` — имя выбранной стратегии (пишет GUI/авто-подбор)
- `kill-proxy.ps1` — корректное завершение всех экземпляров прокси
- `fix-hosts.ps1` — чистка битых записей hosts (бэкап: `hosts.zapret-backup`)
- `show-lan-ip.bat` — адреса для устройств
- `proxy.log` — журнал (ротация 2 МБ), `proxy.pid` — PID запущенного прокси
- `connection-test.txt` — последний отчёт проверки соединения (из GUI)
- `gui-settings.json` — размер/позиция окна, последняя вкладка, режим трея
- `diagnostics-*.txt` — отчёты диагностики, сохранённые из GUI

## Безопасность

- Подключения принимаются **только из приватных сетей** (192.168/10/172.16),
  интернет-клиенты отклоняются.
- Прокси не подключается к приватным/зарезервированным адресам сам
  (защита от SSRF и зацикливания).
- Брандмауэр дополнительно ограничивает вход только подсетями LAN.

## Если что-то не работает

- Сайт не открывается на устройстве → проверь, что zapret запущен на ПК
  (`tasklist | findstr winws`) и прокси жив (`show-lan-ip.bat`, `proxy.log`).
- Какой-то сайт ломается при включённом zapret → `zapret-stop.bat` и
  попробуй другую стратегию из корня (`general.bat`, `general (FAKE TLS AUTO).bat`,
  `general (ALT*).bat`) — пакет специально содержит альтернативы.
- Не знаешь, какая стратегия лучше → открой **ZAPRET CONTROL** → **Тесты** →
  **Авто-подбор стратегии** (или **Быстрый подбор (HTTP)**).
- Приложение не запускается → запусти `ZapretControl.exe` ещё раз и подтверди
  UAC; при ошибке смотри `self-test.txt` в этой папке.

## Удаление

`uninstall-proxy.bat` от имени администратора.
